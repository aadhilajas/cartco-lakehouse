# Assignment deliverables

`week1/` through `week4/` preserve dated submissions, screenshots, video links and
historical evidence. `milestones/` contains reserved assignment directories.
The directories record project progress; they are not the current setup guide.

Start with the [current overview](../README.md),
[live website](https://cartco-lakehouse.vercel.app/),
[verification report](../docs/test_report.md) and
[walkthrough plan](../docs/project-walkthrough.md).

Keep genuine recording links, original dates and failed-run history. Do not
replace historical screenshots or backdate new evidence to satisfy a milestone.
A prepared GIF or written walkthrough is not a narrated recording. The Week 3
recorded link and the pending final narrated walkthrough are separate items.

The personal resume material retained in the old Week 4 submission is historical;
it is not an active project task. Empty milestone directories should be reviewed
against the actual submission requirements before removal or population.
